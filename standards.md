# Standards implemented

This project implements the following [standards](https://gitea.crzynet.com/crzynet/homelab-configs/src/branch/main/standards)
from the crzynet `homelab-configs` repo. Each row pins the **version** that this
project has actually wired up.

| Standard | Version | Adopted | Notes |
|---|---|---|---|
| [handoff-prompt-workflow](https://gitea.crzynet.com/crzynet/homelab-configs/src/branch/main/standards/handoff-prompt-workflow/README.md) | 2.0.0 | 2026-11-21 | `prompts/TEMPLATE.md` copied verbatim; snippet pasted verbatim into `CLAUDE.md`; decision log at `docs/decisions.md`. |
| [code-checkin-and-pr](https://gitea.crzynet.com/crzynet/homelab-configs/src/branch/main/standards/code-checkin-and-pr/README.md) | 1.2.0 | 2026-11-21 | CI in `.github/workflows/ci.yml` (Lint, Config validation, Compose validation; push-only). Image build check is `docker-publish.yml`'s PR build (job `build`). SAST via CodeQL default setup. Registry retention on GHCR (`retention.yml`); Docker Hub is frozen at v0.4.2 and gets none. **Not applicable:** migration check (no database). **Exempt:** test suite (no tests yet). `refactor:` commit prefix is a project extension. Ruleset "Require PR for Main" requires `build`, `Lint`, `Config validation`, `Compose validation`, and a CodeQL `code_scanning` rule (applied 2026-11-21). CodeQL thresholds are `none`/`none`: the scan must complete, but findings don't block merge (per the standard; STD instead blocks on errors / high-or-higher). |
| [release-prep-and-cut](https://gitea.crzynet.com/crzynet/homelab-configs/src/branch/main/standards/release-prep-and-cut/README.md) | 1.1.0 | 2026-11-21 | Root `VERSION` file (bare semver, source of truth; logged at startup); `docker-publish.yml` guards release tag == `VERSION`; commands in `.claude/commands/`. README has no version badge or What's New section, so the README sync step only updates existing version references. Adds a project-specific cross-repo gate (STD wire contract) to `/release-prep`. |
| ~~[vexp-context-engine](https://gitea.crzynet.com/crzynet/homelab-configs/src/branch/main/standards/vexp-context-engine/README.md)~~ | 3.0.0 _(sunset)_ | de-adopted 2026-11-21 | Removed per the v3.0.0 removal guide: guard hook, `.claude/settings.json` hook entry, vexp-generated `.claude/CLAUDE.md` and `.github/copilot-instructions.md` (commit `ee7d907`), and the `.gitignore` entry. No `mcp__vexp__*` allows or `.vexpignore` existed. Host install already gone (host teardown is owned by `ansible`). Was wired but never recorded as a standards adoption. |

Not adopted: [repo-sandbox-permissions](https://gitea.crzynet.com/crzynet/homelab-configs/src/branch/main/standards/repo-sandbox-permissions/README.md) — this repo is worked on from a dedicated dev VM where Claude Code runs unsandboxed; the VM is the isolation boundary.
